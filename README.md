# Story

Three short Indonesian notes stored as plain text, kept while practicing Git and GitHub.

## Features

- `firstAttempt.txt` — a single line: `ini yang pertama`
- `secondAttempt.txt` — a single line: `ini yang kedua`
- `thirdAttempt.txt` — a single line: `ini yang ke tiga`

## Tech stack

Plain text files tracked with Git.

## Setup

Git is the only requirement.

```bash
git clone https://github.com/inasfarras/Story.git
cd Story
```

## Usage

Read each note from the repository root:

```bash
cat firstAttempt.txt
cat secondAttempt.txt
cat thirdAttempt.txt
```
